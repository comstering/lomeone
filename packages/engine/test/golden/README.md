# 골든 테스트 데이터

공식 계산기 결과를 정답으로 고정해 두고 엔진 결과와 원 단위로 비교한다 (PRD §18).
이 폴더의 파일은 **언어와 무관한 계약**이다. 나중에 백엔드(Kotlin)가 같은 계산을 하게 되면 같은 파일로 테스트한다.

| 파일 | 내용 | 스토리 |
| --- | --- | --- |
| `salary.csv` | 연봉 실수령액 30건 | US-005 |
| `sim-scenarios.*` | 시뮬레이션 손계산 5건 | US-013 (예정) |

## salary.csv 채우는 법

### 열 구성

| 열 | 누가 채우나 | 설명 |
| --- | --- | --- |
| `case_id` ~ `children_8_to_20` | 미리 채움 | 입력값. 부양가족은 **본인 포함** |
| `ref_monthly_gross` | 미리 채움 | 연봉 ÷ 12, 원 미만 버림 (참고용) |
| `ref_monthly_taxable` | 미리 채움 | 월 급여 − 비과세. **공식 계산기에 넣는 값** |
| `national_pension` ~ `employment` | 사람 | 4대보험 근로자 부담분 (원) |
| `income_tax`, `local_income_tax` | 사람 | 간이세액표 소득세·지방소득세 (원) |
| `checked_at_4insure`, `checked_at_nts` | 사람 | 조회한 날짜 `YYYY-MM-DD` |
| `purpose` | 미리 채움 | 이 조합을 넣은 이유 |
| `memo` | 사람 | 이상한 점, 계산기 화면의 특이사항 |

### 1. 4대보험 — 4대사회보험 정보연계센터 모의계산

<https://www.4insure.or.kr/pbiz/ntcn/inscSmlCalcView.do>

1. 월 급여(보수월액)에 `ref_monthly_taxable`을 넣는다.
2. **근로자 부담분**을 각 열에 옮긴다: 국민연금 → `national_pension`, 건강보험 → `health`, 장기요양 → `long_term_care`, 고용보험 → `employment`.
3. 고용보험은 근로자 부담(실업급여)만 적는다. 사업주 부담 항목은 무시한다.

### 2. 소득세 — 국세청 근로소득 간이세액표 조회

홈택스(<https://www.hometax.go.kr>)에서 "근로소득 간이세액표"를 검색해 조회 화면으로 들어간다.

1. 월급여액(비과세 제외)에 `ref_monthly_taxable`을 넣는다.
2. 공제대상가족 수 = `dependents`, 8세 이상 20세 이하 자녀 수 = `children_8_to_20`.
3. 원천징수 비율은 **100%**로 둔다 (review.md C-6).
4. 소득세 → `income_tax`, 지방소득세 → `local_income_tax`.

### 주의

- 조회 시점의 요율이 기준이다. 2026년 7월 1일 이후에 조회하면 `kr/2026-07.json` 룰셋과 비교한다.
- 공식 계산기가 월 급여를 `ref_monthly_gross`와 다르게 처리하는 것 같으면(예: 원 단위 반올림) `memo`에 적는다. 엔진의 월 급여 계산 방식을 그 결과에 맞춘다.
- 값을 고치지 않는다. 엔진 결과와 다르면 엔진을 고친다. 계산기 쪽이 의심되면 `memo`에 적고 다시 조회한다.
- 요율이 바뀌면(2027년 1월) 이 파일을 새로 만든다. 이전 파일은 `salary-2026.csv`처럼 연도를 붙여 보관한다.

## 조합 설계

30건은 다음을 빠짐없이 덮도록 골랐다.

- **연봉 범위**: 2,400만원(정적 페이지 시작) ~ 1억 5,000만원
- **국민연금 상한**: 직전(S20), 경계(S21: 과세 월 659만원), 초과(S22·S23)
- **간이세액표 최상단**: 월 1,000만원(S27), 초과 산식 구간(S28·S29·S30)
- **나누어떨어지지 않는 연봉**: S08, S14 (월 급여 끝전 처리 확인)
- **비과세 유무 쌍**: S01/S02, S09/S10
- **부양가족 1~4명, 자녀 0~2명**: 소득세 0원 가능 구간(S03) 포함
- **PRD 대표값**: 계산기 기본값 4,000만원(S09), 대표 검색어 4,200만원(S12)
