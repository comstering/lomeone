# BACKEND-REQUESTS — 백엔드(사용자 구현)에 요청할 API

프론트 설계가 끝나면 필요한 엔드포인트·스키마·에러·제약을 여기에 모아 전달한다.
근거: PRD `LM-PRD-00` §8(F-01~F-06, F-20), §9.2, §10.3.

## 지금까지 확정된 요구 (PRD 기준, 초안)
- 인증 없음. **총무 키**(22자 base62)·**응답자 토큰**으로 권한 판별. 서버는 해시로 저장. 키 없으면 수정·확정·삭제 불가 (SC-12).
- 모임 ID: 무작위 base62 10자.
- 모든 모임에 `expires_at`(마지막 날짜/확정일 + 90일, D-3 미확정) — 서버가 자동 삭제.
- 만료/삭제된 모임 조회는 구분 가능한 응답 (프론트가 `/gone` 표시).
- 엔드포인트 후보: 모임 생성·조회·확정/확정취소·삭제, 응답 제출·수정(같은 이름 중복 처리), (P1) 장소·마감.
- rate limit, 모임 ID 열거 차단은 서버 책임.
- 응답 슬롯 표현 방식(비트맵 vs 인덱스 배열)은 협의 필요.

> 상세 스키마는 Q-1(계약 방식) 결정 후 작성.
