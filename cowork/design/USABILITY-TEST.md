## 1. 준비물

- 참가자 5명: 로미원을 모르는 20–40대, **iOS 2–3 · Android 2–3**, 전원 카톡 사용, 최소 3명은 단톡방 총무 경험자.
- **링크는 카톡 1:1 메시지로 보내서 카톡 인앱 브라우저로 열게 한다** (실제 맥락). 참가자 본인 폰 사용.
- 대면 또는 영상통화 화면 공유, 1인 15분, 녹화 동의서(구두 가능), 보상 커피 쿠폰.
- 진행자는 **힌트를 주지 않는다.** 막히면 "편하신 대로 해 보세요"만. 10초 이상 멈추면 기록하고 "어떤 생각 중이세요?"만 묻는다.
- 테스트 URL(개발 세션이 채움): `______________________`
  - 과제 1 시작: `/screens/m.html?v=name&coach=0` (코치마크 없이 — 발견성 확인용. 코치마크 효과를 보려면 `coach` 없이 한 번 더)
  - 과제 2 시작: `/screens/m.html?v=result`
  - 과제 3 시작: `/screens/new.html`
- **A안은 5명 모두 과제 1에서 처음 본다** (판정은 A안의 오조작만 센다). 과제 1 직후 시간이 남으면 B안(`m.html?v=paint&alt=b&coach=0`)을 보여 주고 의견만 듣는다 (판정에는 쓰지 않음).

### 과제 1 — 참여자로 응답하기 (DAC-02·03)
- 말로 전달: "친구가 단톡방에 이 링크를 올렸어요. 이번 주 수·목·금 중에 **저녁(7–9시쯤)이나 목요일 오전 10–12시**가 가능하다고 알려 주세요. 이름은 본인 이름으로요."
- 시작: 카톡 메시지의 링크 탭 → 이름 입력 화면.
- 성공: 응답 제출 완료 토스트/결과 화면 도달. 칠한 칸이 목표(수 19–21, 금 19–21, 목 10–12)와 **같은가**도 기록.
- 관찰: 이름 입력에서 멈춤 / 칠하는 동작 발견까지 시간 / **스크롤하려다 칠함 횟수** / 칠한 걸 지우려고 한 횟수 / 제출 버튼을 찾는 시간.

### 과제 2 — 결과 읽기 (DAC-04)
- 말로 전달: "응답이 다 모였어요. **모두가 되는 시간 중 가장 좋은 때가 언제인지** 알려 주세요."
- 성공: 1위 카드(수 10/29 19:00–21:00)를 말하거나 짚는다. 응답자 칩이나 히트맵만 보고 틀리게 답하면 실패.
- 관찰: 답하기까지 시간 / 어디를 먼저 봤는지(추천 카드 vs 히트맵 vs 응답자 칩) / "빠지는 사람" 표시를 이해했는지.

### 과제 3 — 총무로 만들고 확정하기
- 말로 전달: "단톡방 동창회 약속을 잡으려고 해요. **다음 주말(토·일) 중 저녁 시간**으로 링크를 만들어 단톡방에 보내 보세요."
- 이어서(결과 화면 `m.html?v=admin`에서): "응답이 모였어요. **가장 좋은 시간으로 확정**해 주세요."
- 성공: 링크 만들기 → 공유 시트 도달 → (확정) 확인 시트에서 [확정하기].
- 관찰: 빠른 날짜 칩 사용 여부 / 비활성 버튼 이유 안내를 읽었는지 / **총무 링크 안내를 이해했는지**(질문 §5-3) / 확정 확인 시트에서의 망설임.

## 4. 사전 질문 (2분)
1. 단톡방에서 약속 시간을 정해 본 적 있어요? 어떻게 했어요?
2. 일정 조율 도구(에브리타임 시간표 합치기, 타임트리, 구글 폼 등)를 써 본 적 있어요?
3. 카톡으로 받은 링크를 열 때 보통 어떤 점이 신경 쓰여요? (로그인·개인정보 등)

## 5. 마무리 질문 (2분)
1. 가장 헷갈렸던 순간은 언제였어요?
2. (칠하기) 손가락으로 칠하는 게 자연스러웠어요? 스크롤이랑 헷갈린 적 있어요?
3. (총무) "총무 링크도 챙겨 두세요 / 이 링크는 단톡방에 올리지 마세요" 문구를 보고 무엇을 하라는 뜻이라고 이해했어요?
4. 이 링크를 단톡방에서 받으면 열어 볼 것 같아요? 어떤 점 때문에 망설일 것 같아요?
5. 친구에게 이 서비스를 한 줄로 소개한다면?

## 6. 결과 정리 (11/12 목)
- 위 집계표 → D-8 판정(A안 유지 / B안 채택) → 결과를 `QUESTIONS.md`와 `PROGRESS.md`에 기록, B안이면 `grid.js`의 `alt=b`를 기본값으로 하고 A안 코드는 `assets/archive/`로.

## 7. 알려진 한계 (테스트 전 공유)
- 시안은 정적 파일이라 **실제 제출·저장이 없다** (제출하면 결과 화면으로 이동할 뿐). 결과 화면의 응답은 샘플 5명이다.
- 시안의 "오늘"은 2026-10-28로 고정이다. 과제 문구의 날짜(수·목·금 10/29–31)는 이 기준이라, 테스트 날짜와 어긋나도 참가자에게는 "이번 주"라고만 말한다.
- 카톡 공유 버튼·`.ics` 저장은 토스트만 뜬다.
