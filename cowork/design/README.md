## 시안의 핵심 방향 (요약)

- **색 1개로 행동을 이끌어요.** 브랜드 색 2안(민트 틸 / 코발트) 중 선택 필요 (D-5). 히트맵은 같은 색의 농도 6단계, "전원 가능"은 색 + 테두리 + 줄무늬.
- **엄지 영역.** 모든 핵심 버튼은 하단 고정 바. 칠하기 그리드는 셀 = 칠하기, 시간축 = 스크롤(A안)과 칠하기 모드 토글(B안)을 둘 다 만들어 두었어요 (D-8 테스트용).
- **결과는 글자로.** 히트맵보다 "가장 좋은 시간" 카드가 위에 있고, 1위는 크게·전원 배지, 빠지는 사람은 이름으로 (호박색, 빨강 아님).
- **확정 카드는 캡처용.** 시간이 가장 크게, 브랜드 색 꽉 채움.
- 막다른 길(404·만료)과 결과 화면 끝은 모두 "새 약속 만들기"로 이어져요 (참여자 → 다음 총무).

## 현황

화면 SCR-01~12, OG·카카오 템플릿(SCR-13·14), 컴포넌트 C-01~32(C-26 제외)는 시안에 있어요.
**사용성 테스트·실제 카톡 인앱 확인·색각 이상 검증은 아직이에요.** 자세한 현황은 `QUESTIONS.md` §D와 `DESIGN-SPEC.md` §9.

## 기술 메모

프레임워크 없는 HTML/CSS/JS. `assets/js/*.js`는 시안 동작용이라 **그대로 쓰지 말고 참고용**이에요 (헤더·푸터·아이콘을 JS로 주입하므로 마크업은 각 컴포넌트 클래스 표 `DESIGN-SPEC.md` §3 기준으로 보세요). 폰트는 Pretendard (CDN).
