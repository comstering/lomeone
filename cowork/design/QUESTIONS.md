## D. 시안에서 일부러 뺀 것 / 아직 안 한 것 (솔직한 현황)

- **사용성 테스트(DAC-02·03·04, D-8)는 아직 못 했어요.** 시안 HTML로 테스트하면 되지만 실제 사용자 5명이 필요해요. 2차 검수에서는 웹 인터페이스 가이드라인·detector·360/320px 실측·색각 시뮬레이션(계산)까지만 했어요 (`PROGRESS.md` §3 "검수 결과").
- **실제 기기(카톡 인앱 브라우저)에서의 확인은 못 했어요.** 시안에는 `?inapp=1`로 상·하단 카톡 바를 흉내 내는 미리보기만 있어요 (보이는 높이 약 580px).
- 한 번도 안 그린 상태: 응답 마감(P1), 총무 키 없음 안내(Q-08), 모임 수정 화면, 날짜만·요일 모드 결과(Q-04), 응답자 20명+ 펼치기(S-06), 로딩 스켈레톤(전체 화면 공통).
- 다크 모드는 토큰·전 화면에서 동작해요(`?theme=dark`). 색각 이상은 계산 시뮬레이션만 했고(사람 확인 아님), VoiceOver/TalkBack 같은 **실제 스크린리더 확인은 아직이에요.**
- OG 이미지는 **HTML 템플릿**이에요(`screens/og.html`). 실제 PNG 렌더링(서버)은 개발 쪽에서 `1200×630` 템플릿을 그대로 옮기면 돼요.
- 로고는 SVG 시안(`assets/logo/`)이에요. 파비콘 16/32/180 PNG 내보내기와 단색·다크 버전은 D-5 확정 후 만들게요.
- 색 대비는 주요 조합만 계산해서 확인했어요 (`DESIGN-SPEC.md` §2 표). 전수 검사는 아직이에요.
